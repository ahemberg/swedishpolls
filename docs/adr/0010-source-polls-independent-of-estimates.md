# Source polls remain available independently of estimates

On 2026-09-15, the owner chose to make collected polls available on the homepage and in charts independently of estimate publication, so the existing statistical release block does not prevent visitors from browsing source observations. Current poll views continue to show the latest collected data once estimates are published, with poll markers and published estimates shown together; publication-specific views retain their original inputs and immutable semantics under [ADR 0007](0007-publications-are-immutable-documents.md). This adds a source-data view alongside the publication-based view and does not authorize an estimator release or a waiver.

The homepage presents the available polls, charts and table without messaging about unfinished estimates or internal plans. Sections and navigation that require model results are omitted until those results exist. A visit keeps the chart, table and CSV on one source snapshot; a page refresh selects the latest retained snapshot. Background data updates run at 03:00 Europe/Stockholm instead of every thirty minutes. An empty database triggers immediate collection on startup; ordinary restarts serve retained data and wait for the nightly job. Direct links to pages requiring unavailable model results temporarily redirect to the overview. The agreed display and filtering behavior is recorded in the [design interview in #173](https://github.com/ahemberg/swedishpolls/issues/173).
